# ComputeNet Core

ComputeNet is an open research protocol for verifiable useful compute.

Status:
- Open Public Testnet v0.11
- Mainnet not launched
- Research preview only

Principles:
- No premine
- No ICO
- No founder allocation
- Open source before genesis
- Public participation from genesis

This repository contains:
- Truth Stack
- verification pipeline
- validator replay logic
- receipt generation
- attestation systems
- protocol APIs
